# DLS - сборщик данных для ДСР Photocor

---

## Что делает
Данная программа собирает xlsx файл используя подготовленный файл **Сырые данные.xlsx** и приложенные TXT файлы
с данными по каждому из образцов.
При обработке данных используются имена образцов в формате "Группа_Образец".
В файле **Сырые данные.xlsx** страницы должны быть названы точно также, как и "Группа".
Программа автоматически определяет путь до соответствующих файлов за сегодня,
но должны быть соблюдены следующие условия:
* Основная папка Photocor должна быть на рабочем столе
* В ней должна быть папка с номером текущего года
* В ней папка с именем текущего месяца с большой буквы
* В ней папка с датой в формате ддммгг

Если файлы лежат в другой папке, то в поле "Путь к папке" можно указать актуальный путь.

---

## Как использовать
После запуска программа автоматически проводит поиск TXT файлов за сегодня.
Если нужны файлы за другой день, то в поле даты можно ввести имя другой папки и нажать "Повторить поиск".
Ниже выводится список найденных TXT файлов, которые будут взяты в работу,
**Сырые данные.xlsx** отображаться не будет.
Для работы программы обязательно в той же папке должен быть файл **Сырые данные.xlsx**.
Если количество файлов верно, то можно указать инициалы оператора (опционально) и нажать "Создать .xlsx",
что сгенерирует соответствующий файл туда же, откуда запущена программа.
После завершения работы по созданию xlsx файла можно проверить правильность работы программы и,
если всё верно, можно "Обсчитать файлик", что добавит этот в этот файл таблицы с результатами по пикам.

---

## Комментарий по сборке программы
После сборки файл весит 12.3 Мб, но его можно сжать через UPX, что уменьшит его размер до 3.61 Мб.
